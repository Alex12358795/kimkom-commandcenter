SuperTCG Barcode Button
=======================
Generates internal EAN-13 style barcode for products via a manual button.

Features
========
* Adds an "Add barcode" button to the product form
* Generates a valid, scannable EAN-13 barcode with prefix ``20`` (internal range)
* Prevents overwriting existing barcodes
* Auto-reloads the form so the barcode appears immediately

Configuration
=============
Nothing to configure.
